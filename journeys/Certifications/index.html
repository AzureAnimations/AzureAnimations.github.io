The climb

Five rungs, from “I use it” to “I design it”

Every rung is a real place to stop. You do not have to reach the top — most people find their level and stay there, and that is exactly how it is meant to work.

1

Use Copilot in your day job

There is no certification here, and that is the point. Microsoft ships official one-day courses for people who just want to get more done. No exam, no proctor — you finish and you can use the thing.

3

Prove you can do the job — Associate

This is where a certification starts matching a job title. You are expected to have done the work, not just read about it. Associate certifications renew every 12 months, free, online.

People already working in the role
AZ-104 Azure Administrator Associate Identity, storage, compute, virtual networking AZ-700 Azure Network Engineer Associate Hybrid connectivity, delivery, network security
Every Associate certification, live from Microsoft Learn →

Check before you book. Microsoft retired several well-known Azure Associate exams during 2026 — including AZ‑204 Developer, AI‑102 AI Engineer and AZ‑500 Security Engineer. Always open the certification page itself before you start studying.

4

Design the whole thing — Expert

Expert is the only level with a genuine gate: you must already hold the Associate below it. That is not bureaucracy — you cannot design a system you have never had to operate.

Architects · leads · senior engineers

5

GitHub, on its own track

GitHub certifications are separate from the Microsoft ones — different site, different registration, their own badges. There are exactly five, and Foundations is the way in.

Developers · DevOps · platform engineers
● Foundations Git basics, repositories, collaboration, GitHub products Start here ▶ Actions Workflow automation and software pipelines Automation 🛡️ Advanced Security Vulnerability identification and workflow security Security 🔧 Administration Repository management and a healthy GitHub estate Admin ✨ Copilot Prompt engineering, responsible AI, testing with Copilot AI-assisted development

⚠️

A course is not a certification. MS-4018 is a one-day course — there is no exam and no badge at the end of it. AB-900 is a certification — a proctored exam that earns you a badge you can put on LinkedIn. Both are official, both are useful, and mixing them up is the single most common mistake people make when planning their year.
