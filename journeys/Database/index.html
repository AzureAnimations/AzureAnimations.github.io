What AI-200 expects from these databases

The AI-200 study guide asks you to be comfortable with the skills below. The engine stops above walk through them in a visual, hands-off way.

Azure Cosmos DB for NoSQL

  • Use the SDK and write queries
  • Set the indexing policy and consistency level for efficient RU use
  • Store embeddings and run vector search
  • React to changes with the change feed processor

Azure Database for PostgreSQL

  • Use the SDK and write queries
  • Design schemas and indexes
  • Measure and reduce pgvector latency
  • Size compute, memory and storage for vector workloads
  • Build RAG with metadata filters
  • Optimize connections

Not covered yet: Azure Managed Redis is also on the AI-200 study guide, but it is not part of this journey yet.

Recap

Four stops that matter

Whichever engine you pick, the path is the same: choose it on purpose, build a solid foundation, add vectors for AI, then tune for cost and speed. The architect track is there when you need the wider data platform.

  1. PickMatch the workload to Cosmos DB or PostgreSQL before you build.
  2. Build and queryConnect with the SDK, model your data, and write efficient queries.
  3. Add vectorsStore embeddings and run similarity search with metadata filters.
  4. OptimizeTune indexes, consistency and connections for latency and cost.
