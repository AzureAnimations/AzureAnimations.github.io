How it works

How these lessons work

The same four moves in every lesson.

  1. 1

    Copy a prompt

    Each step gives you a prompt that is ready to copy.

  2. 2

    Try it in the app

    Paste it into Outlook, Teams, Word or PowerPoint.

  3. 3

    Check the answer

    Compare it with the sample files. Does it say the right thing?

  4. 4

    Review before you act

    Fix what is wrong. Only then use it.

Copilot proposes. You decide.

Get ready

Before you start

  • A Microsoft 365 account with Copilot
  • Word, PowerPoint, Outlook and Teams
  • One hour for each story lesson
  • Use only the fictional files
For instructors

Teaching this? Keep the pace in your hands.

Every lesson has a Present mode and presenter notes, so you can lead a room with confidence.

Run-of-show tips
  • The lessons are standalone. Pick any lesson in any order.
  • Nothing moves on its own. You set the pace.
  • Every lesson has a Present mode and presenter notes.
  • The suggested-time pills are manual. Use them as a guide.
  • Review every Copilot answer with the group.
  • Do not send drafts during training.
  • Add ?bar=off to a lesson link to hide the control bar.
