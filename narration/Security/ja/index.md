## Step 1 · Welcome to the Azure Security Journey

[warm] Azure セキュリティ ジャーニーへようこそ。
[500ms]
[confident] これは Azure 上の Contoso のアプリです。ブラウザー、App Service の Web 層、Function App、そしてそのデータが、5 つの構成要素で保護されています。
[500ms]
[calm] まずは Key Vault でコードからシークレットを取り除き、次に App Configuration で設定を一元管理します。Managed Identity と Service Principal を使えば、アプリと自動化処理は保存されたシークレットなしでサインインでき、Zero Trust がそのすべてをプライベート ネットワークで包み込みます。
