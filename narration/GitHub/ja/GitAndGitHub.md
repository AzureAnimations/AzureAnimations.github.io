## Step 3 · Git Is the Tool, GitHub Is the Platform

[curious] この二つを混同しがちなので、ここで分けて考えましょう。Gitはあなたのコンピュータ上で動作する分散型バージョン管理ツールです。

[confident] GitHub Gitリポジトリをホストし、その上にコラボレーション機能を追加しています。Gitはオープンソースで、 GitHubなしでも問題なく動作します。
[600ms]
[calm] パソコンとGitHubの間で、プッシュ、プル、クローンムーブのコミットを繰り返します。

## Step 4 · Repository, Commit, Branch

[600ms]

[curious] 支店は別の仕事の分野で、準備ができるまではメインとは別に扱われます。

## Step 6 · GitHub Flow: Six Simple Moves

[curious] GitHubフローは軽量で分岐ベースのワークフローです。分岐作業を行い、レビューを求め、統合し、整理します。
[600ms]
[confident] まずブランチしてコミットし、デフォルトのブランチから安全に作業を離して作業を保ちます。
[600ms]
[calm] その後、プルリクエストでフィードバックを求め、マージで変更がメインに届きます。各移動はウェブサイト、コマンドライン、またはデスクトップGitHubで行えます。

## Step 7 · Review, Merge, Done
