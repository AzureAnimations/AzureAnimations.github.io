## Step 1 · Without History, Edits Collide

[calm] El equipo meteorológico de Contoso envía una API de promociones y el equipo comparte un archivo de promociones.
[600ms]
[concerned] Las copias se acumulan, y una edición sobrescribe silenciosamente a otra.
[600ms]
[serious] No hay historia ni forma segura de trabajar en paralelo. El equipo necesita una historia compartida y una mejor forma de trabajar juntos.

## Step 2 · Version Control Remembers Every Change

[curious] El control de versiones registra qué cambió, quién lo cambió, cuándo y por qué.
[600ms]
[confident] Como se recuerda cada cambio, cualquier versión anterior puede recuperarse.
[600ms]
[optimistic] Y hace posible el trabajo paralelo, a través de ramas.

## Step 3 · Git Is the Tool, GitHub Is the Platform

[curious] La gente confunde estos dos, así que vamos a separarlos. Git es una herramienta de control de versiones distribuida que funciona en tu ordenador.
[600ms]
[confident] GitHub aloja repositorios de Git y añade colaboración encima. Git es de código abierto y funciona bien sin GitHub.
[600ms]
[calm] Push, pull y clone commits de movimiento entre tu ordenador y GitHub.

## Step 4 · Repository, Commit, Branch

[calm] Tres ideas que debes saber. Un repositorio guarda tus archivos y el historial de cada uno.
[600ms]
[confident] Un commit es una instantánea en el tiempo, guardada con un mensaje. Cada commit real tiene un autor, una hora y un mensaje.
[600ms]
[curious] Una sucursal es una línea de trabajo separada, que se mantiene separada de la principal hasta que estés listo.

## Step 5 · Accounts: You, Your Team, Your Company

[calm] Inicias sesión en una cuenta personal, con GitHub Free o GitHub Pro.
[600ms]
[confident] Las organizaciones reúnen equipos, con cuentas, equipos y roles compartidos.
[600ms]
[reflective] Las cuentas empresariales gestionan muchas organizaciones, con políticas centrales y facturación. Los planes cambian, así que consulta la página de planes de GitHub.

## Step 6 · GitHub Flow: Six Simple Moves

[curious] GitHub flujo de trabajo es ligero, basado en ramas. Trabajas en una rama, pides una revisión, fusionas y luego recoges.
[600ms]
[confident] Primero haces ramas y haces commit, lo que mantiene tu trabajo seguro alejado de la rama predeterminada.
[600ms]
[calm] Luego una pull request pide retroalimentación y una fusión lleva los cambios a la página principal. Puedes hacer cada movimiento en la web, la línea de comandos o en GitHub escritorio.

## Step 7 · Review, Merge, Done

[calm] Aquí está el flujo en acción. Maya abre una solicitud de pull desde su sucursal.
[600ms]
[confident] Ravi lo revisa y aprueba los cambios. Luego la solicitud de tirada se fusiona y la sucursal se elimina.
[600ms]
[reassuring] Eliminar la rama es seguro. La pull request y sus commits permanecen, y la rama puede restaurarse.

## Step 8 · Markdown Makes Issues and PRs Clear

[curious] Markdown convierte símbolos en texto plano en encabezados, listas, listas de tareas y código.
[600ms]
[confident] Un cartel de at menciona a una persona y la notifica. Un hash y un número enlazan a un problema o pull request.
[600ms]
[calm] Funciona en descripciones de issues y pull requests, en comentarios y en archivos README.

## Step 9 · Pick the Tool That Fits the Moment

[curious] Es el mismo repositorio, pero con puertas diferentes: la web, GitHub Escritorio, GitHub Móvil, un editor o la línea de comandos.
[600ms]
[confident] GitHub Desktop es una aplicación gratuita y de código abierto para Windows y macOS, con Git visual y sin comandos que memorizar.
[600ms]
[calm] GitHub Móvil, para Android y iOS, trae notificaciones, reseñas y comentarios a tu teléfono.

## Step 10 · Git and GitHub Basics, All in One

[calm] Recapitulemos. El control de versiones guarda el historial, Git es la herramienta y GitHub es donde el equipo trabaja en conjunto.
[600ms]
[confident] Has cubierto repositorios, commits, ramas, cuentas, flujo GitHub, Markdown y elegir la herramienta adecuada.
[600ms]
[proud] Estos son los conceptos básicos de la guía de estudio de G H 900, y los caminos de aprendizaje de Microsoft Learn son tu siguiente paso.
