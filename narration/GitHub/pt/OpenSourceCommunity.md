## Step 1 · Great code lives outside our repo

[calm] A equipe de meteorologia da Contoso quer reutilizar código de fora do seu próprio repositório.
[600ms]
[concerned] Enquanto isso, outras equipes continuam reconstruindo as mesmas ferramentas.
[600ms]
[curious] Então, como podemos reutilizar e compartilhar? Vamos ver como funciona a comunidade GitHub e como suas ideias ajudam dentro de uma empresa.

## Step 2 · Open source: share it, and fund it

[calm] Código aberto pode ser usado, alterado e compartilhado sob sua licença, e as comunidades o constroem.
[600ms]
[confident] Os benefícios são colaboração, transparência, flexibilidade e apoio comunitário.
[600ms]
[optimistic] GitHub Sponsors permite que você pague às pessoas que mantêm o que você consegue, seja uma vez ou mensalmente.

## Step 3 · A public repo that welcomes people

[curious] Um repositório público está aberto a todos, que podem visualizá-lo e fazer fork.
[600ms]
[confident] Uma licença, uma READMEe diretrizes de contribuição mostram aos visitantes como usá-las e participar, e as Discussões lhes dão um espaço para conversar.
[600ms]
[serious] Sem uma licença, o direito autoral padrão se aplica, então ninguém mais pode reutilizar o código.

## Step 4 · Make it easy to find

[curious] Como as pessoas encontram um repositório? Dê uma breve descrição, tópicos, um READMEe uma licença.
[600ms]
[confident] Os tópicos classificam um repositório por assunto, então ele aparece na busca, no Explore e nas páginas de tópicos.
[600ms]
[calm] Os tópicos usam letras minúsculas, números e hífens. Você pode somar até vinte por repositório.

## Step 5 · Contribute with a fork and a pull request

[curious] E se você não tiver acesso de escrita a um projeto? Faça um fork para conseguir sua própria cópia.
[600ms]
[confident] Clone, envie sua alteração e abra um pull request para que os mantenedores possam revisar e mesclar o projeto upstream.
[600ms]
[reassuring] Um fork permanece conectado ao repositório upstream, e você pode fazer fork em qualquer repositório público.

## Step 6 · Fork, template, or clone?

[curious] Fork, template e clone copiam um repositório, mas para funções diferentes.
[600ms]
[confident] Faça um fork para contribuir com o projeto de outra pessoa. Use um template para começar um novo projeto da mesma forma. Clone para trabalhar em uma cópia localmente.
[600ms]
[calm] Um fork mantém o histórico de commit, enquanto um repositório feito a partir de um template começa com um único commit.

## Step 7 · Follow, star, watch: three signals

[calm] Três sinais mantêm você informado. Siga pessoas e organizações para ver a atividade pública delas no seu feed.
[600ms]
[confident] Estrele um repositório para salvá-lo e demonstre gratidão aos seus mantenedores.
[600ms]
[curious] Assista a um repositório para receber notificações sobre isso, e você pode limitá-las a eventos como lançamentos ou discussões.

## Step 8 · GitHub Marketplace: extend GitHub

[curious] GitHub Marketplace lista ferramentas que ampliam seu fluxo de trabalho.
[600ms]
[confident] As ações são automações reutilizáveis, e os aplicativos se integram com GitHub. Algumas são gratuitas e outras pagas.
[600ms]
[calm] Qualquer pessoa pode publicar uma ação. Apenas aplicativos pertencentes a organizações podem vender planos pagos, após a verificação do editor.

## Step 9 · InnerSource: open source inside the company

[curious] InnerSource é quando uma empresa aplica as práticas de código aberto ao código proprietário.
[600ms]
[confident] As equipes tornam os repositórios internos visíveis, aceitam pull requests de outras equipes e documentam como contribuir.
[600ms]
[reassuring] Repositórios privados também funcionam. Comece com um projeto piloto, defina critérios de sucesso e peça feedback.

## Step 10 · The GitHub community, inside and out

[calm] O código aberto oferece Contoso código para reutilizar e uma forma de retribuir.
[600ms]
[confident] InnerSource traz os mesmos hábitos para suas próprias equipes.
[600ms]
[proud] Esta página cobre o domínio Explore a comunidade GitHub do exame G H 900. Os caminhos de aprendizagem abaixo vão mais a fundo.
