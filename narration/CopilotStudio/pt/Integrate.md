# Narrator Script — Copilot Studio · Extend & Integrate · PT

**Source animation:** `static/v2/CopilotStudio/Integrate.html`

Voz masculina (pt-BR-Macerio). Um bloco por etapa.

---

## Step 1 · Why Extend

[confident] Sozinho, um agente consegue manter uma ótima conversa. Mas uma boa resposta muitas vezes precisa de um sistema real.
[600ms]
[calm] O banco de dados de pedidos, a ferramenta de tíquetes, uma API interna: o agente precisa alcançá-los para ajudar de verdade.
[600ms]
[impressed] Estender é o que transforma o agente de "falar sobre as coisas" em "fazer as coisas acontecerem", agindo sobre os dados reais da Contoso.

## Step 2 · Connectors

[confident] O caminho mais fácil: os conectores — e o Copilot Studio já vem com mais de mil, prontos para usar.
[600ms]
[calm] Eles são compartilhados com o Power Automate, o Power Apps e o Azure Logic Apps: Dataverse, SharePoint, SQL Server, ServiceNow, Salesforce e centenas de outros.
[600ms]
[impressed] Adicione um como ferramenta e o agente pode chamá-lo no meio da conversa, sem código. É bem provável que o sistema de que você precisa já tenha um conector esperando.

## Step 3 · Custom Connectors

[confident] Não há conector pronto para o seu sistema? Envolva qualquer API REST em um conector personalizado.
[600ms]
[calm] Você descreve a API — sua URL base, a autenticação e os endpoints — e depois define seus gatilhos e ações, como "StartReturn" ou "GetStatus".
[600ms]
[reassuring] A API interna de devoluções da Contoso não tem conector pronto, então um personalizado a transforma em uma ferramenta de primeira classe: reutilizável em toda a Power Platform e certificável para compartilhar em todo o locatário.

## Step 4 · MCP

[confident] E mais recente ainda: adicione ferramentas de um servidor Model Context Protocol, o MCP.
[600ms]
[calm] Na aba Tools, escolha "Add a tool" e depois "Model Context Protocol". Escolha um conector MCP pronto da Microsoft ou conecte o seu próprio servidor por URL.
[600ms]
[impressed] Um padrão aberto, muitas ferramentas: um servidor MCP pode expor tanto ferramentas QUANTO recursos, ótimo para serviços, bancos de dados e APIs próprios.

## Step 5 · Agent Flows + Azure

[confident] Para uma lógica de negócio mais pesada e de várias etapas, apoie o agente com fluxos de agente e o Azure.
[600ms]
[calm] Fluxos de agente para automação de várias etapas, Azure Logic Apps para fluxos de trabalho corporativos, Power Automate para aprovações, Azure Functions para código personalizado sob demanda.
[600ms]
[impressed] O baixo código encontra toda a pilha de integração do Azure: o agente pode executar um processo corporativo real, direto de um chat.

## Step 6 · Autonomous & Multi-Agent

[confident] E ele nem precisa esperar por um chat.
[600ms]
[calm] Gatilhos de evento deixam o agente agir por conta própria, e agentes filhos deixam ele delegar a especialistas. Uma nova linha chega ao Dataverse e o agente de Operações da Contoso dispara.
[600ms]
[impressed] Ele roteia para um agente de Reconciliação que mescla duplicatas, um agente de Finanças que trata reembolsos e um agente de Notificação que avisa o responsável: reagindo, reconciliando e roteando sem intervenção humana.

## Step 7 · Recap

[confident] Então aí está toda a superfície de integração, em um só mapa.
[600ms]
[calm] Conectores: mais de mil, sem código. Conectores personalizados: envolva qualquer API REST. MCP: pronto ou o seu próprio servidor. Fluxos e Azure para a lógica corporativa. E autonomia quando você estiver pronto.
[600ms]
[encouraging] Comece com um conector pronto e recorra aos conectores personalizados, ao MCP, aos fluxos e à autonomia conforme a necessidade crescer. Quer se aprofundar? A trilha "Extend and manage Copilot Studio agents" no Microsoft Learn é a sua próxima parada.
