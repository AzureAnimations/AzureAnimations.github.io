## Step 1 · Welcome

[confident] Te damos la bienvenida al recorrido de bases de datos para aplicaciones de IA.
[600ms]
[encouraging] Acompaña a Contoso al elegir una base de datos, crear, buscar y optimizar; la ruta de arquitecto es opcional.

## Step 2 · One database cannot do it all

[confident] Una sola base de datos no puede con todo.
[600ms]
[encouraging] Conoce al equipo de especialistas detrás del asistente de soporte de IA de Contoso, mira la ruta del recorrido y descubre cómo encajan las rutas de desarrollador y de arquitecto.

## Step 3 · Pick your database for AI apps

[confident] Elige tu base de datos para aplicaciones de IA.
[600ms]
[encouraging] Compara Azure Cosmos DB for NoSQL y Azure Database for PostgreSQL para cargas de trabajo de IA, y sabrás qué ruta seguir y por qué.

## Step 4 · Cosmos DB: build and query

[confident] Cosmos DB: crear y consultar.
[600ms]
[encouraging] Conéctate con el SDK, trabaja con elementos y escribe consultas SQL que lean documentos para aplicaciones de IA.

## Step 5 · Cosmos DB: vector search

[confident] Cosmos DB: búsqueda vectorial.
[600ms]
[encouraging] Almacena embeddings, ordena resultados con VectorDistance, añade filtros de metadatos y búsqueda híbrida, y mantén los embeddings sincronizados con la fuente de cambios.

## Step 6 · Cosmos DB: optimize performance

[confident] Cosmos DB: optimizar el rendimiento.
[600ms]
[encouraging] Analiza los patrones de consulta, configura índices de rango y compuestos, elige un tipo de índice vectorial y selecciona un nivel de coherencia que equilibre actualidad y costo.

## Step 7 · PostgreSQL: build and query

[confident] PostgreSQL: crear y consultar.
[600ms]
[encouraging] Diseña esquemas, escribe SQL eficiente y conéctate desde Python con autenticación segura de Microsoft Entra.

## Step 8 · PostgreSQL: vector search with pgvector

[confident] PostgreSQL: búsqueda vectorial con pgvector.
[600ms]
[encouraging] Almacena embeddings con pgvector, compara métricas de distancia y crea patrones de recuperación para RAG, búsqueda semántica y recomendaciones.

## Step 9 · PostgreSQL: optimize vector search

[confident] PostgreSQL: optimizar la búsqueda vectorial.
[600ms]
[encouraging] Ajusta PostgreSQL y pgvector, elige índices vectoriales, da forma al diseño de los datos, escala para el volumen y agrupa conexiones.

## Step 10 · Contoso ships the assistant

[confident] Contoso lanza el asistente.
[600ms]
[encouraging] Sigue una pregunta de un cliente a través del historial de chat, la búsqueda vectorial, una consulta de pedidos y el ajuste, y comprueba cómo participa cada motor que has aprendido.

## Step 11 · Design relational data storage

[confident] Diseñar el almacenamiento de datos relacionales.
[600ms]
[encouraging] Elige entre SQL Database, SQL Managed Instance y SQL Server on Azure VMs, y planifica la escalabilidad, la disponibilidad y la seguridad.

## Step 12 · Design data integration and data lake

[confident] Diseñar la integración de datos y el lago de datos.
[600ms]
[encouraging] Compara Data Factory, Data Lake, Databricks y Synapse, planifica las rutas activa, templada y fría, y añade Stream Analytics para datos en streaming.

## Step 13 · Choose your next step

[confident] Elige la ruta que encaje con tu próximo proyecto.
[600ms]
[encouraging] Practica con la formación de Microsoft Learn enlazada y vuelve aquí cuando necesites aprender otra habilidad de bases de datos.
