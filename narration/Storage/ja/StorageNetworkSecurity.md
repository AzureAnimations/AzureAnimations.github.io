# ナレーション台本 — Azure Storage · レベルアップ · ネットワークと Private Link

**Source animation:** `static/v2/Storage/StorageNetworkSecurity.html`

---

## Step 1 · goal

[confident] 既定では、あなたのストレージアカウントにはパブリックエンドポイントがあります。インターネット上のどこからでもアクセスできてしまいます。
[600ms]
[calm] 私たちの目標は、それをパブリックインターネットから外し、信頼するネットワークだけが到達できるようにすることです。
[700ms]
[serious] そして始める前に一つ重要な考え方を。ネットワーク規則と ID は独立した層です。一方は要求がどこから来るかを制御し、もう一方は誰が行動する権限を持つかを制御します。

## Step 2 · firewall

[confident] 最初の層はストレージファイアウォールです。有効にすると、既定のアクションは拒否に変わります。
[600ms]
[calm] これで、あなたが許可した IP 範囲と仮想ネットワークだけがアカウントに到達でき、それ以外はすべて拒否されます。
[700ms]
[reassuring] 信頼されたサービスの例外を追加して、バックアップや監視といった Azure 自身のサービスが通り続けられるようにしましょう。

## Step 3 · pe

[confident] 次に、プライベートエンドポイントを追加します。Azure Private Link を通じて、あなた自身のサブネットのプライベート IP をアカウントの前に置きます。
[600ms]
[calm] storage へのトラフィックは、これでパブリックインターネットではなく、あなたのプライベートネットワークを通ります。
[700ms]
[serious] 知っておくべき細かい点 — プライベートエンドポイントを作っただけでは、パブリックエンドポイントは自動的にはオフになりません。それは別のステップです。

## Step 4 · dns

[confident] そのプライベート IP を実際に使わせるには、名前がそれに解決される必要があります。それを担うのがプライベート DNS ゾーンです。
[600ms]
[calm] private-link ゾーンがアカウントのホスト名をプライベートアドレスに向けるので、あなたのネットワーク内のクライアントは自動的にプライベートに到達します。
[700ms]
[reassuring] 仮想ネットワークの外からは、同じ名前が依然としてパブリックに解決されます。だからこそ次のステップが重要なのです。

## Step 5 · lockdown

[confident] さあ、正面玄関を閉めます。パブリックネットワークアクセスを無効に切り替えましょう。
[600ms]
[calm] ここから先、プライベートな経路が唯一の入り口です。
[700ms]
[serious] 名前解決とアクセス制御は独立していることを思い出してください。パブリックアクセスを無効にすることこそが、本当にそれを固く守るのです。

## Step 6 · connect

[confident] 端から端まで、実際に動くところを見てみましょう。サブネットで動くあなたのアプリが、storage の URL をプライベート IP に解決します。
[600ms]
[calm] あなたのプライベートネットワークを通じて直接つながります。パブリックインターネットへの寄り道は一切ありません。
[700ms]
[encouraging] 多数のリソースの間で、さらに厳しく制御したいですか？ ネットワークセキュリティ境界を追加しましょう。

## Step 7 · recap

[proud] これが全体像です。既定拒否のファイアウォール、次にプライベートエンドポイント、次にプライベート DNS、そしてパブリックアクセスをオフに。
[700ms]
[encouraging] 既定拒否のファイアウォールとともにプライベートエンドポイントを選んでください。それがストレージを本当にプライベートに保つパターンです。

## Step 8 · spec

[confident] もう一段深く。ストレージのネットワークを制御する方法は三つあります。
[600ms]
[calm] IP 規則と仮想ネットワーク規則を持つファイアウォール。パブリックアドレスは保ちつつ誰が使えるかを制限するサービスエンドポイント。そして、インターネットへの露出なしにプライベート IP を与えるプライベートエンドポイント。
[700ms]
[reassuring] 真の分離のためには、プライベートエンドポイントが勝ります。プライベートアドレスで、あなたのネットワークからのみアクセス可能です。
