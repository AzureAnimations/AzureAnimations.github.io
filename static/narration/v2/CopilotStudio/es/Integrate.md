# Narrator Script — Copilot Studio · Extend & Integrate · ES

**Source animation:** `static/v2/CopilotStudio/Integrate.html`

Voz masculina (es-ES-Tristan). Un bloque por paso.

---

## Step 1 · Why Extend

[confident] Por sí solo, un agente puede mantener una gran conversación. Pero una buena respuesta a menudo necesita un sistema real.
[600ms]
[calm] La base de datos de pedidos, la herramienta de tickets, una API interna: el agente necesita alcanzarlos para ayudar de verdad.
[600ms]
[impressed] Extender es lo que convierte al agente de "hablar de las cosas" a "hacer que las cosas pasen", actuando sobre los datos reales de Contoso.

## Step 2 · Connectors

[confident] La vía más fácil: los conectores, y Copilot Studio incluye más de mil, listos para usar.
[600ms]
[calm] Se comparten con Power Automate, Power Apps y Azure Logic Apps: Dataverse, SharePoint, SQL Server, ServiceNow, Salesforce y cientos más.
[600ms]
[impressed] Añade uno como herramienta y el agente puede llamarlo en plena conversación, sin código. Lo más probable es que el sistema que necesitas ya tenga un conector esperando.

## Step 3 · Custom Connectors

[confident] ¿No hay conector listo para tu sistema? Envuelve cualquier API REST en un conector personalizado.
[600ms]
[calm] Describes la API —su URL base, la autenticación y los endpoints— y luego defines sus desencadenadores y acciones, como "StartReturn" o "GetStatus".
[600ms]
[reassuring] La API interna de devoluciones de Contoso no tiene conector listo, así que uno personalizado la convierte en una herramienta de primera clase: reutilizable en Power Platform y certificable para compartir en todo el inquilino.

## Step 4 · MCP

[confident] Y más nuevo aún: añade herramientas desde un servidor de Model Context Protocol, o MCP.
[600ms]
[calm] En la pestaña Tools, elige "Add a tool" y luego "Model Context Protocol". Escoge un conector MCP de Microsoft listo para usar, o conecta tu propio servidor por URL.
[600ms]
[impressed] Un estándar abierto, muchas herramientas: un servidor MCP puede exponer tanto herramientas COMO recursos, ideal para servicios, bases de datos y APIs propios.

## Step 5 · Agent Flows + Azure

[confident] Para una lógica de negocio más pesada y de varios pasos, respalda al agente con flujos de agente y Azure.
[600ms]
[calm] Flujos de agente para la automatización de varios pasos, Azure Logic Apps para flujos de trabajo empresariales, Power Automate para aprobaciones, Azure Functions para código personalizado bajo demanda.
[600ms]
[impressed] El bajo código se encuentra con toda la pila de integración de Azure: el agente puede ejecutar un proceso empresarial real, directo desde un chat.

## Step 6 · Autonomous & Multi-Agent

[confident] Y ni siquiera tiene que esperar a un chat.
[600ms]
[calm] Los desencadenadores de eventos permiten que un agente actúe por su cuenta, y los agentes hijos le permiten delegar en especialistas. Llega una nueva fila a Dataverse y el agente de Operaciones de Contoso se activa.
[600ms]
[impressed] Enruta a un agente de Reconciliación para fusionar duplicados, a un agente de Finanzas para gestionar reembolsos y a un agente de Notificación para avisar al responsable: reacciona, reconcilia y enruta sin intervención humana.

## Step 7 · Recap

[confident] Así que ahí está toda la superficie de integración, en un solo mapa.
[600ms]
[calm] Conectores: más de mil, sin código. Conectores personalizados: envuelve cualquier API REST. MCP: listo para usar o tu propio servidor. Flujos y Azure para la lógica empresarial. Y autonomía cuando estés listo.
[600ms]
[encouraging] Empieza con un conector listo para usar y recurre a los conectores personalizados, MCP, flujos y autonomía a medida que crezca la necesidad. ¿Quieres profundizar? La ruta "Extend and manage Copilot Studio agents" en Microsoft Learn es tu siguiente parada.
